恒邦股份（002237）年报摘要

数据来源：2024年、2025年年度报告 黄金冶炼龙头，连续多年位居"中国黄金十大冶炼企业第一名"。控股股东为江西铜业股份有限公司（2019年至今），实际控制人为江西省国资委。以造锍捕金为核心工艺，具备无氰冶金技术。银产能1,200吨/年（2025年扩产后），黄金产能109.817吨/年。

1.3 产量波动分析（同比变化超过10%的品种）

黄金（2024年大幅增长+29.91%）： - 主因：2024年合质金（合质金指含金物料外购加工）采购量较上年增加65.41%，外购合质金直接增加黄金产出 - 2025年增速放缓至+3.95%，黄金自产量（非外购）48.68%大增，主因威海恒邦含金多金属矿有价元素综合回收技术改造项目投产

白银（2024年下降-13.31%，2025年大幅回升+28.02%）： - 2024年下降主因：原料结构调整，复杂金精矿处理比例变化影响阳极泥产出 - 2025年回升主因：威海恒邦综合回收技改项目投产，伴生银回收量增加；第四套火法冶金系统（富氧侧吹+顶吹）投运提升整体处理能力

电解铜（2025年大幅增长+30.66%）： - 主因：子公司威海恒邦矿冶发展有限公司含金多金属矿有价元素综合回收技术改造项目投产，电解铜产能大幅释放

硫酸（2025年大幅增长+51.76%）： - 主因：威海恒邦综合回收技改项目投产，冶炼烟气增加带动硫酸产出

1.4 火法冶金系统（2025年）

公司拥有4套火法冶金系统： 1. 富氧底吹熔炼造锍捕金+熔炼烟气骤冷收砷系统 2. 富氧底吹熔炼+粉煤底吹直接还原系统 3. 富氧侧吹熔炼系统 4. 富氧侧吹+顶吹熔炼系统（新增第四套）

  • 持续考察中亚、东南亚、澳洲等重点区域

三、年报重点与研究员需知

3.1 公司战略方向

  • 核心定位：专业黄金冶炼企业，以金银为主打产品
  • 战略路径：夯实黄金冶炼主业 + 多金属综合回收（Au、Ag、Cu、Pb、Zn、Bi、Sb、Te、As、Se）
  • 产业链延伸：向稀散金属、高纯金属新材料、半导体材料领域布局
  • 国际化：海外矿山直接采购，增强原料渠道控制力
  • 控股股东江西铜业（2019年入主），实际控制人江西省国资委

3.2 成本结构

黄金冶炼（2025年）：

毛利率结构（2025年）： - 黄金毛利率：0.39%（收入占比69.08%，冶炼加工费极薄） - 白银毛利率：3.18%（收入占比8.47%） - 电解铜毛利率：2.68%（收入占比15.84%） - 硫酸毛利率：60.92%（收入占比0.57%，高毛利副产） - 锌锑铋硒等金属毛利率：46.63%（收入占比0.78%，高毛利稀散金属） - 铅毛利率：15.60%

研究员注意：公司是典型的冶炼加工型模式，原材料成本占比超77%，黄金毛利率仅0.39%，利润极度依赖加工量规模和稀散金属（铋、锑、碲、砷、硒）的高毛利贡献。硫酸毛利率高达60.92%（副产，几乎无边际成本），是重要的利润弹性来源。

3.3 储量/资源量

  • 截至报告期末，已完成储量备案的查明金资源储量约150.10吨（2025年末），150.38吨（2024年末）
  • 公司较少动用自有矿山资源开发，冶炼用原材料主要依靠外购
  • 自有矿山包括威海恒邦、杭州建铜、栖霞金兴等

3.5 主要风险

  1. 原材料价格波动风险：高度依赖外购金精矿、复杂金精矿，原料成本占大头
  2. 黄金冶炼毛利率极低（0.39%）：利润对加工量和金银价格极度敏感
  3. 存货风险：2025年经营活动现金流转负，存货规模大幅增长
  4. 审计意见分歧：2024年独立董事王咏梅对年报投反对票，质疑和信会计师事务所更换签字会计师（2025年已更换为安永华明）
  5. 环保压力：砷产品化处置虽是优势，但环保标准持续趋严
  6. 产能消化：2025年大幅扩产后，产能利用率仍有提升空间（电解铜仅75.7%）

3.6 核心竞争优势

  • 黄金冶炼龙头：连续多年"中国黄金十大冶炼企业第一名"
  • 造锍捕金核心工艺：火法无氰冶金技术，全面淘汰湿法提金
  • 全球砷治理"恒邦模式"：精三氧化二砷→金属砷→高纯砷全产业链
  • 多金属综合回收：金、银、铜、铅、锌、铋、锑、碲、砷、硒闭路循环
  • 4套火法冶金系统：处理多元素复杂金精矿能力国内领先
  • 江铜集团背景：控股股东江西铜业提供资源和资金支持
  • 海外采购网络：秘鲁、赞比亚子公司，覆盖全球主要产矿区
